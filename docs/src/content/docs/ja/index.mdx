## このリポジトリの役割

<CardGrid>
  <Card title="🎨 デザイントークンの唯一真源">
    9 つの JSON 中性ソース（カラー / タイポグラフィ / 間隔 / 角丸 / シャドウ / モーション / 階層 / コンポーネントレベル）。schema が厳格に制約し、プラットフォーム固有の構文は一切許可されない。
    [トークンフォーマット](/ja/tokens/token-format)
  </Card>
  <Card title="📐 コンポーネント契約">
    コンポーネントごとに 1 つの JSON 契約：props / 列挙 / デフォルト値 / イベント / スロット / 振る舞い。命名正規表現が 5 端での統一を保証する。
    [契約フォーマット](/ja/specs/spec-format)
  </Card>
  <Card title="🧪 ゴールデンケース">
    クロスプラットフォームで翻訳可能な given/when/then の振る舞いレベルのアサーション——ロジックは共有せず、振る舞いを共有する。
    [ケースフォーマット](/ja/cases/case-format)
  </Card>
  <Card title="⚙️ クロスプラットフォーム codegen">
    1 セットの中性トークンから Android（Kotlin）/ iOS（Swift）/ HarmonyOS（ArkTS）/ Windows（C#）4 端の言語スケルトンを生成。骨組みのみで、実装は生成しない。
    [パイプライン概要](/ja/codegen/pipeline)
  </Card>
  <Card title="🌙 ダークモードの事前計算">
    Web 血脈の `color-mix()` はビルド時にフラットな色値へ事前計算され、ネイティブ端のランタイムコストはゼロになる。
    [ダークモードのマージ](/ja/tokens/dark-mode)
  </Card>
  <Card title="🔗 ローカル連携">
    ファミリーレイアウトの下でトークンを変更し codegen を再実行すれば即時反映。存在性ガード付きで、パッケージの公開は不要。
    [ローカル連携](/ja/guide/local-linking)
  </Card>
</CardGrid>
