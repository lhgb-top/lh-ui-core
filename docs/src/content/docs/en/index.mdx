## What this repository does

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 Single source of truth for design tokens">
    9 platform-neutral JSON sources (color / typography / spacing / radius / shadow / motion / elevation / component-level), strictly schema-constrained, with no platform-specific syntax allowed.
    [Token Format](/en/tokens/token-format)
  </Card>
  <Card title="📐 Component contracts">
    One JSON contract per component: props / enums / defaults / events / slots / behaviors, with naming regular expressions guaranteeing consistency across the five targets.
    [Contract Format](/en/specs/spec-format)
  </Card>
  <Card title="🧪 Golden cases">
    Cross-platform translatable given/when/then behavior-level assertions — logic is not shared, behavior is.
    [Case Format](/en/cases/case-format)
  </Card>
  <Card title="⚙️ Cross-platform codegen">
    One set of neutral tokens generates the language skeletons for Android (Kotlin) / iOS (Swift) / HarmonyOS (ArkTS) / Windows (C#) — skeletons only, never implementations.
    [Pipeline Overview](/en/codegen/pipeline)
  </Card>
  <Card title="🌙 Dark mode precomputation">
    The web bloodline's `color-mix()` is precomputed to flat color values at build time, at zero runtime cost for the native targets.
    [Dark Mode Merging](/en/tokens/dark-mode)
  </Card>
  <Card title="🔗 Local linking">
    Under the family layout, changing a token and re-running codegen takes effect immediately — with existence guards, no publishing required.
    [Local Linking](/en/guide/local-linking)
  </Card>
</CardGrid>
