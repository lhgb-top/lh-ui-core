## ما الذي يفعله هذا المستودع

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 المصدر الأصلي الوحيد لرموز التصميم">
    9 مصادر JSON محايدة (الألوان / الطباعة / المسافات / الزوايا / الظلال / الحركة / الترتيب الطبقي / مستوى المكوّنات)، مع قيود صارمة عبر الـ schema، ويُمنع أي صياغة خاصة بمنصة بعينها.
    [تنسيق الرموز](/ar/tokens/token-format)
  </Card>
  <Card title="📐 عقود المكوّنات">
    عقد JSON واحد لكل مكوّن: props / القيم المُعدَّدة / القيم الافتراضية / الأحداث / الفتحات / السلوكيات، مع تعابير قياسية للأسماء تضمن التوحيد عبر الأطراف الخمسة.
    [تنسيق العقد](/ar/specs/spec-format)
  </Card>
  <Card title="🧪 الحالات الذهبية">
    تأكيدات سلوكية given/when/then قابلة للترجمة عبر الأطراف —— لا تُشارك البنية المنطقية، وإنما السلوك.
    [تنسيق الحالات](/ar/cases/case-format)
  </Card>
  <Card title="⚙️ توليد الكود عبر الأطراف">
    مجموعة واحدة من الرموز المحايدة، تُولّد الهياكل اللغوية لأربع جهات أصلية: Android (Kotlin) / iOS (Swift) / HarmonyOS (ArkTS) / Windows (C#) —— هياكل فقط، دون أي تطبيقات.
    [نظرة عامة على خط الأنابيب](/ar/codegen/pipeline)
  </Card>
  <Card title="🌙 الحساب المسبق للوضع الداكن">
    تُحسب قيم `color-mix()` الخاصة بسلالة الويب مسبقًا في وقت البناء إلى قيم ألوان مسطحة، دون أي تكلفة في وقت التشغيل على الأطراف الأصلية.
    [دمج الوضع الداكن](/ar/tokens/dark-mode)
  </Card>
  <Card title="🔗 الربط المحلي">
    في تخطيط العائلة، يكفي تعديل الرمز وإعادة تشغيل codegen ليصبح التغيير فوريًا، مع وجود حراسة للتحقق من الوجود، ودون الحاجة إلى النشر.
    [الربط المحلي](/ar/guide/local-linking)
  </Card>
</CardGrid>
