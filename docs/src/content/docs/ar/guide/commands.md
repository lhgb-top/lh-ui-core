## البناء

| الأمر | الوظيفة |
| --- | --- |
| `pnpm codegen` | تشغيل عملية التوليد كتابةً في `dist/` (يحذف أولًا ثم يبني) |
| `pnpm build` | `pnpm codegen && pnpm verify` |

## التحقق

| الأمر | الوظيفة |
| --- | --- |
| `pnpm verify:tokens` | التحقق من الرموز: schema + سلامة المراجع + **تباين النص الأساسي مع لون الخلفية ≥4.5:1 (WCAG AA، يفحص الأزواج المُعلَنة فقط، مع إعفاء الحالة المعطَّلة)** + **فحص الصياغة الخاصة بالمنصات (يعترض `var()` / `rem` / `sp` / `dp` وغيرها)** + تقرير المسارات الداكنة اليتيمة |
| `pnpm verify:specs` | التحقق من اتساق المواصفات (specs) مع الحالات (cases) |
| `pnpm verify` | دمج الأمرين السابقين |

## الاختبار والفحص الساكن

| الأمر | الوظيفة |
| --- | --- |
| `pnpm test` | اختبارات اللقطات (vitest run) |
| `pnpm test:watch` | وضع المراقبة لاختبارات اللقطات |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm lint` | eslint |
| `pnpm lint:fix` | eslint --fix |
| `pnpm format` | تنسيق json/md/yml عبر prettier |

## موقع التوثيق

| الأمر | الوظيفة |
| --- | --- |
| `pnpm docs:dev` | معاينة محلية على `http://localhost:5185/lhui/core/` (يتطابق base مع الإنتاج) |
| `pnpm docs:build` | بناء للإنتاج (base `/lhui/core/`) |
| `pnpm docs:preview` | معاينة بناء الإنتاج |

## الإصدار

| الأمر | الوظيفة |
| --- | --- |
| `pnpm changeset` | كتابة مجموعة تغييرات (changeset) |
| `pnpm changeset:status` | عرض حالة مجموعات التغييرات |
| `pnpm changeset:version` | تعديل رقم الإصدار وفق مجموعات التغييرات |

## تحديث اللقطات

بعد تعديل الرموز أو القوالب ستفشل اللقطات حتمًا، وبعد التأكد من صحة التغييرات:

```bash
pnpm test -- -u
```

## نظرة على السكربتات

السكربتات الموجودة تحت `scripts/` (غير المسجَّلة في npm scripts):

| السكربت | الوظيفة |
| --- | --- |
| `scripts/verify-tokens.mts` | التنفيذ الفعلي للتحقق من الرموز |
| `scripts/verify-specs.mts` | التنفيذ الفعلي للتحقق من المواصفات |
| `scripts/resolve-local-tokens.mjs` | حراسة الربط المحلي |

يتم النشر عبر changesets (راجع قسم «الإصدار» أعلاه)، ولا توجد سكربتات نشر إضافية.
