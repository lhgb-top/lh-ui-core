## 这个仓是做什么的

<CardGrid>
  <Card title="🎨 设计令牌唯一真源">
    9 份 JSON 中性源（色板 / 排版 / 间距 / 圆角 / 投影 / 动效 / 层级 / 组件级），schema 强约束，禁止任何平台专属语法。
    [令牌格式](/tokens/token-format)
  </Card>
  <Card title="📐 组件契约">
    每组件一份 JSON 契约：props / 枚举 / 默认值 / 事件 / 插槽 / 行为，命名正则保证五端统一。
    [契约格式](/specs/spec-format)
  </Card>
  <Card title="🧪 黄金用例">
    可跨端翻译的 given/when/then 行为级断言——逻辑不共享，行为共享。
    [用例格式](/cases/case-format)
  </Card>
  <Card title="⚙️ 跨端 codegen">
    一套中性令牌，生成 Android（Kotlin）/ iOS（Swift）/ 鸿蒙（ArkTS）/ C 四端语言骨架，只生骨架不生实现。
    [管线总览](/codegen/pipeline)
  </Card>
  <Card title="🌙 暗色预计算">
    web 血脉的 `color-mix()` 在构建期预计算为字面色值，原生端零运行时成本。
    [暗色合并](/tokens/dark-mode)
  </Card>
  <Card title="🔗 本地联动">
    家族布局下改令牌重跑 codegen 即时生效，带存在性守卫，无需发包。
    [本地联动](/guide/local-linking)
  </Card>
</CardGrid>
