## 이 리포지터리가 하는 일

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 디자인 토큰 유일 원본">
    9개의 JSON 중성 소스(색판 / 타이포그래피 / 간격 / 모서리 둥글기 / 그림자 / 모션 / z-index / 컴포넌트 수준). schema가 강하게 제약하며, 어떤 플랫폼 전용 구문도 금지합니다.
    [토큰 형식](/ko/tokens/token-format)
  </Card>
  <Card title="📐 컴포넌트 계약">
    컴포넌트마다 JSON 계약 한 부: props / 열거형 / 기본값 / 이벤트 / 슬롯 / 동작. 명명 정규식으로 다섯 플랫폼의 통일을 보장합니다.
    [계약 형식](/ko/specs/spec-format)
  </Card>
  <Card title="🧪 골든 케이스">
    크로스 플랫폼으로 번역 가능한 given/when/then 동작 수준 어서션 — 로직은 공유하지 않고, 동작을 공유합니다.
    [케이스 형식](/ko/cases/case-format)
  </Card>
  <Card title="⚙️ 크로스 플랫폼 codegen">
    하나의 중성 토큰 세트로 Android(Kotlin) / iOS(Swift) / HarmonyOS(ArkTS) / Windows(C#) 4개 플랫폼의 언어 골격을 생성합니다. 골격만 생성하고 구현은 생성하지 않습니다.
    [파이프라인 개요](/ko/codegen/pipeline)
  </Card>
  <Card title="🌙 다크 사전 계산">
    Web 혈통의 `color-mix()`를 빌드 시 미리 평면 색상값으로 계산하여, 네이티브 측의 런타임 비용을 0으로 만듭니다.
    [다크 모드 병합](/ko/tokens/dark-mode)
  </Card>
  <Card title="🔗 로컬 연결">
    가족 레이아웃에서 토큰을 바꾸고 codegen을 다시 실행하면 즉시 반영됩니다. 존재 여부 가드가 있어 패키지를 게시할 필요가 없습니다.
    [로컬 연결](/ko/guide/local-linking)
  </Card>
</CardGrid>
