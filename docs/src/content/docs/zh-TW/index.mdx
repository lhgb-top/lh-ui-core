## 這個倉是做什麼的

<CardGrid>
  <Card title="🎨 設計令牌唯一真源">
    9 份 JSON 中性源（色板 / 排版 / 間距 / 圓角 / 投影 / 動效 / 層級 / 元件級），schema 強約束，禁止任何平台專屬語法。
    [令牌格式](/zh-TW/tokens/token-format)
  </Card>
  <Card title="📐 元件契約">
    每元件一份 JSON 契約：props / 列舉 / 預設值 / 事件 / 插槽 / 行為，命名正則保證五端統一。
    [契約格式](/zh-TW/specs/spec-format)
  </Card>
  <Card title="🧪 黃金用例">
    可跨端翻譯的 given/when/then 行為級斷言——邏輯不共享，行為共享。
    [用例格式](/zh-TW/cases/case-format)
  </Card>
  <Card title="⚙️ 跨端 codegen">
    一套中性令牌，生成 Android（Kotlin）/ iOS（Swift）/ 鴻蒙（ArkTS）/ Windows（C#）四端語言骨架，只生骨架不生實作。
    [管線總覽](/zh-TW/codegen/pipeline)
  </Card>
  <Card title="🌙 暗色預計算">
    web 血脈的 `color-mix()` 在構建期預計算為字面色值，原生端零執行時成本。
    [暗色合併](/zh-TW/tokens/dark-mode)
  </Card>
  <Card title="🔗 本地連動">
    家族布局下改令牌重跑 codegen 即時生效，帶存在性守衛，無需發包。
    [本地連動](/zh-TW/guide/local-linking)
  </Card>
</CardGrid>
