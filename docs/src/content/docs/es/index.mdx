## Qué hace este repositorio

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 Fuente única de tokens de diseño">
    9 fuentes JSON neutrales (color / tipografía / espaciado / radio de esquina / sombra / movimiento / jerarquía / nivel de componente), fuertemente restringidas por un esquema, sin ninguna sintaxis específica de plataforma.
    [Formato de tokens](/es/tokens/token-format)
  </Card>
  <Card title="📐 Contratos de componentes">
    Un contrato JSON por componente: props / enumerados / valores por defecto / eventos / slots / comportamientos, con expresiones regulares de nomenclatura que garantizan la unidad entre las cinco plataformas.
    [Formato de los contratos](/es/specs/spec-format)
  </Card>
  <Card title="🧪 Casos dorados">
    Aserciones de comportamiento given/when/then traducibles entre plataformas — la lógica no se comparte, el comportamiento sí.
    [Formato de los casos](/es/cases/case-format)
  </Card>
  <Card title="⚙️ Codegen multiplataforma">
    Un conjunto de tokens neutrales genera los esqueletos de lenguaje para Android (Kotlin) / iOS (Swift) / HarmonyOS (ArkTS) / Windows (C#): solo esqueletos, nunca implementaciones.
    [Visión general del pipeline](/es/codegen/pipeline)
  </Card>
  <Card title="🌙 Precomputación del modo oscuro">
    El `color-mix()` del linaje web se precomputa en tiempo de compilación a valores de color planos, sin coste alguno en tiempo de ejecución para las plataformas nativas.
    [Fusión del modo oscuro](/es/tokens/dark-mode)
  </Card>
  <Card title="🔗 Enlace local">
    Con el diseño de la familia, cambiar un token y volver a ejecutar codegen surte efecto de inmediato, con guardas de existencia y sin necesidad de publicar paquetes.
    [Enlace local](/es/guide/local-linking)
  </Card>
</CardGrid>
