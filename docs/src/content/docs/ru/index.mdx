## Что делает этот репозиторий

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 Единый источник истины для токенов дизайна">
    9 платформенно-нейтральных JSON-источников (цвет / типографика / отступы / скругления / тени / анимация / z-уровни / компонентный уровень), строгая схема, платформо-специфичный синтаксис запрещён.
    [Формат токенов](/ru/tokens/token-format)
  </Card>
  <Card title="📐 Контракты компонентов">
    Один JSON-контракт на компонент: props / перечисления / значения по умолчанию / события / слоты / поведение; регулярные выражения для имен гарантируют единообразие на пяти целевых платформах.
    [Формат контракта](/ru/specs/spec-format)
  </Card>
  <Card title="🧪 Золотые сценарии">
    Переводимые между платформами поведенческие утверждения в формате given/when/then — логика не разделяется, поведение разделяется.
    [Формат сценариев](/ru/cases/case-format)
  </Card>
  <Card title="⚙️ Кроссплатформенный codegen">
    Один набор нейтральных токенов порождает языковые каркасы для Android (Kotlin) / iOS (Swift) / HarmonyOS (ArkTS) / Windows (C#) — только каркасы, без реализаций.
    [Обзор конвейера](/ru/codegen/pipeline)
  </Card>
  <Card title="🌙 Предвычисление тёмной темы">
    `color-mix()` направления web предвычисляется на этапе сборки в плоские значения цветов — нулевая стоимость во время выполнения для нативных платформ.
    [Слияние тёмного режима](/ru/tokens/dark-mode)
  </Card>
  <Card title="🔗 Локальная линковка">
    В рамках семейственной структуры достаточно изменить токен и перезапустить codegen — изменения вступают в силу сразу, с проверкой существования, без публикации пакетов.
    [Локальная линковка](/ru/guide/local-linking)
  </Card>
</CardGrid>
