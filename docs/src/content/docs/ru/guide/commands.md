## Сборка

| Команда | Действие |
| --- | --- |
| `pnpm codegen` | Один шаг генерации, пишет в `dist/` (сначала удаляет, потом создаёт) |
| `pnpm build` | `pnpm codegen && pnpm verify` |

## Проверка

| Команда | Действие |
| --- | --- |
| `pnpm verify:tokens` | Проверка токенов: схема + целостность ссылок + **контрастность ключевого текста/фона >= 4.5:1 (WCAG AA, проверяются только объявленные пары, отключённое состояние exempt)** + **инспекция платформо-специфичного синтаксиса (перехватывает `var()` / `rem` / `sp` / `dp` и т. д.)** + отчёт о путях-сиротах тёмной темы |
| `pnpm verify:specs` | Проверка согласованности specs и cases |
| `pnpm verify` | Объединение двух предыдущих |

## Тесты и статический анализ

| Команда | Действие |
| --- | --- |
| `pnpm test` | Снапшот-тесты (vitest run) |
| `pnpm test:watch` | Снапшот-тесты в режиме наблюдения |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm lint` | eslint |
| `pnpm lint:fix` | eslint --fix |
| `pnpm format` | Форматирование prettier для json/md/yml |

## Сайт документации

| Команда | Действие |
| --- | --- |
| `pnpm docs:dev` | Локальный предпросмотр `http://localhost:5185/lhui/core/` (base совпадает с продакшеном) |
| `pnpm docs:build` | Продакшен-сборка (base `/lhui/core/`) |
| `pnpm docs:preview` | Предпросмотр продакшен-сборки |

## Релизы

| Команда | Действие |
| --- | --- |
| `pnpm changeset` | Написать один changeset |
| `pnpm changeset:status` | Посмотреть состояние changesets |
| `pnpm changeset:version` | Применить изменения версий согласно changesets |

## Обновление снапшотов

После изменения токенов или шаблонов снапшоты неизбежно падают; убедившись, что всё верно:

```bash
pnpm test -- -u
```

## Скрипты

Скрипты в `scripts/` (не зарегистрированные как npm scripts):

| Скрипт | Действие |
| --- | --- |
| `scripts/verify-tokens.mts` | Основная реализация проверки токенов |
| `scripts/verify-specs.mts` | Основная реализация проверки спецификаций |
| `scripts/resolve-local-tokens.mjs` | Защита локальной линковки |

Публикация релизов идёт через changesets (см. раздел «Релизы» выше); отдельных скриптов публикации нет.
