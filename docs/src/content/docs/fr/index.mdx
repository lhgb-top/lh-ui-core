## Que fait ce dépôt

<img class="lh-home-banner" src="/logo-banner.png" alt="lh-ui 品牌横幅" />

<CardGrid>
  <Card title="🎨 Source unique de vérité des jetons de conception">
    9 sources JSON neutres (couleurs / typographie / espacement / rayons / ombres / animation / élévation / niveau composant), contraintes strictes par schéma, aucune syntaxe propre à une plateforme.
    [Format des jetons](/fr/tokens/token-format)
  </Card>
  <Card title="📐 Contrats de composants">
    Un contrat JSON par composant : props / énumérations / valeurs par défaut / événements / slots / comportements, avec des expressions régulières de nommage garantissant l'uniformité des cinq cibles.
    [Format des contrats](/fr/specs/spec-format)
  </Card>
  <Card title="🧪 Cas dorés">
    Des assertions comportementales given/when/then traduisibles d'une plateforme à l'autre — la logique n'est pas partagée, le comportement si.
    [Format des cas](/fr/cases/case-format)
  </Card>
  <Card title="⚙️ Codegen multiplateforme">
    Un seul ensemble de jetons neutres génère les squelettes de langage des quatre cibles native : Android (Kotlin) / iOS (Swift) / HarmonyOS (ArkTS) / Windows (C#) — squelettes uniquement, jamais d'implémentations.
    [Aperçu du pipeline](/fr/codegen/pipeline)
  </Card>
  <Card title="🌙 Précalcul du mode sombre">
    Les `color-mix()` de la lignée web sont précalculés à la compilation en valeurs de couleurs aplaties, à coût d'exécution nul pour les cibles natives.
    [Fusion du mode sombre](/fr/tokens/dark-mode)
  </Card>
  <Card title="🔗 Liaison locale">
    Avec la disposition familiale, modifier un jeton et relancer le codegen prend effet immédiatement — avec des gardes d'existence, aucune publication nécessaire.
    [Liaison locale](/fr/guide/local-linking)
  </Card>
</CardGrid>
